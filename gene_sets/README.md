# GSE183904 Gene Sets

`GSE183904_primary_sender_receiver_signatures_30plus30.tsv` is the fixed, 60-gene primary bulk-projection input: 30 genes for the PLAT-rich fibroblast sender state and 30 for the C1QC+APOE+ macrophage receiver state. `signature_rank` records the original gene-selection order. It is **not** a scoring coefficient. Each available gene contributes equally (`equal_scoring_weight = 1`) to its signature's sample-level mean percentile rank. Unmeasured genes are omitted from that sample's mean. The sender and receiver rank means are each converted to within-cohort Z scores; the mean of those two Z scores is standardized again within the cohort to form the continuous ecological score. No outcome-specific gene weights or response-trained threshold are used.

The 60 primary rows are exported directly from `GSE183904_PLAT_ecosystem_bulk_signatures_frozen.tsv`, which is copied here without alteration. That 120-row source also contains two 30-gene **alternative** signatures: `sender_CXCL14_POSTN_PLAT_state_inclusive` and `receiver_merged_C1QC_axis_excluded`. They are not the primary input and should not be pooled with the 60 primary genes. The primary signatures have `derivation_status = frozen_before_TCGA_outcome_analysis` and exclude the prespecified focal-axis genes. The same 60 primary gene identities and ranks appear in the submission workbook `Supplemental_Tables_1-10.xlsx`, sheet `S6_FigureS6a_TCGA_gene_annotati`.

`GSE183904_Fibroblast_fine_state_top_markers.tsv` and `GSE183904_Myeloid_fine_state_top_markers.tsv` are unmodified source tables of descriptive fine-state markers: 30 genes per cluster across six fibroblast clusters (180 rows) and five myeloid clusters (150 rows). Their within-cluster and outside-cluster expression and detection columns document state annotation. These marker tables are distinct from the two fixed bulk-projection signatures.

`build_gene_sets.py` regenerates the primary TSV from the bundled frozen source table using only the Python standard library. The two marker tables are preserved as source copies. The script validates the two 30-gene ranks, derivation status, focal-axis exclusion and 60 distinct primary gene symbols before writing output.
