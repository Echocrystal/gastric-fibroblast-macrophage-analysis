# Frozen analysis resources

This directory contains frozen, gene-level inputs used by selected scripts in
`../code/`. `RESOURCE_FILE_MANIFEST.tsv` records each source-project path, its
staged copy, size, SHA-256, origin, and public-release recommendation. Copies
retain their original filenames and bytes. These tables contain no individual
patient or sample records.

## Source and reuse notes

- The three `gene_sets/*programs*tsv` files contain selected MSigDB gene sets
  (Hallmark, GO biological process, and Reactome) and, in one case,
  author-curated identity markers. They were prepared with `msigdbr` 26.1.0.
  The base receiver program table was generated by
  `../code/scripts/08_freeze_myeloid_receiver_programs.R`; its virtual-KO
  subset was generated by
  `../code/scripts/19_freeze_virtual_knockout_sanity_universe.py`.
  Cite MSigDB and retain its [license terms](https://www.gsea-msigdb.org/gsea/msigdb_license_terms.jsp)
  when publishing the archive. The listed collections contain no KEGG or
  BioCarta programs.
- `ligand_receptor/lr_network_human_21122021_frozen.tsv` and
  `ligand_receptor/lr_gene_universe_frozen.tsv` derive from the NicheNet-v2
  human network by Robin Browaeys,
  [Zenodo record 7074291](https://doi.org/10.5281/zenodo.7074291), licensed
  CC BY 4.0. The project uppercased symbols, consolidated duplicate
  ligand-receptor pairs and source annotations, and added benchmark flags and
  availability flags from GSE206785 and GSE183904. The gene-universe table
  lists unique genes from the resulting network with availability flags.
  The source freezing script is `../code/scripts/01_freeze_lr_universe.R`.
  This attribution and change description should accompany any public copy.
- The remaining tables are project-derived signatures, state modules, gene
  universes, or matched controls. Patient-count fields are aggregated counts.

`gene_sets/GSE183904_PLAT_ecosystem_bulk_signatures.tsv` is byte-identical to
`../gene_sets/GSE183904_PLAT_ecosystem_bulk_signatures_frozen.tsv` (SHA-256
`76eaecd5519dea8abe1df79603fe41f030b86327cca106319d2eead12757500f`).
The extra filename preserves the path expected by existing analysis scripts;
these are not separate signatures.

The original NicheNet RDS is available from the Zenodo record above and is not
redistributed here. Other scripts may still need processed matrices and
resources outside this staging package; see `../docs/RELEASE_READINESS.md`.
