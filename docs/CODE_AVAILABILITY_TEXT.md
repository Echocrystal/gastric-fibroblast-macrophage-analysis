# Manuscript wording after the release decision

Use only the option that describes the actual state at submission.

## After a public repository is created and checked

> Code availability: The analysis scripts, frozen signature gene lists and
> random-seed registry are available at [repository URL]
> (version [tag or commit]). Public input datasets and accessions are listed
> in the Data sharing statement and Supplementary Methods.

Replace both bracketed fields with real values. A DOI can be added after an
archived release exists. Do not say that all results are reproducible with a
single command unless a clean-environment rerun has been verified.

## If code cannot be released publicly at this revision

> Code availability: The analysis scripts and frozen signature gene lists are
> available from the corresponding author upon reasonable request.

The second statement is an availability commitment. The corresponding author
must be able to provide the files described by it. It is weaker than a public
repository for answering a reproducibility concern.

The existing Data sharing statement should retain the GEO, TCGA, treatment
cohort, cell-line and numerical source-data information already present.
